First Run Setup

ftp2s3

Set up the local panel, PostgreSQL metadata connection, S3-facing defaults, and the first admin account from the UI.

PostgreSQL

The object metadata database can be unavailable during setup. The panel will stay online and apply the saved PostgreSQL-backed settings later.

Admin Account

This creates the first panel admin in SQLite. After setup, logins do not depend on PostgreSQL.

S3 Defaults

These values are saved into PostgreSQL when available. If PostgreSQL is down, they are staged and applied automatically once it comes back.

`FTP_TIMEOUT` stays in the Settings page after setup so local runtime tuning is separate from first-run onboarding.
